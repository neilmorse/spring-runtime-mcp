# 小型生产调度器 XXL-JOB：功能、稳定性与可用性验收

日期：2026-10-23。目标：在另一个真实生产使用、规模较小的 Spring Boot 4 调度器上重复
本地隔离验收，覆盖 SSO、MyBatis/MariaDB、原生 Actuator 和数据库暂停/恢复。只访问自行
启动的回环目标，不部署执行器、不执行任务、不连接生产调度器。

复现资产见 [examples/xxl-job-matrix](../../examples/xxl-job-matrix/README.md) 和
[check_xxl_job_runtime.py](../../scripts/check_xxl_job_runtime.py)。

## 隔离与适配

- MariaDB 11.2 一次性容器，数据库和用户由随机密码创建，只发布到回环随机端口；schema
  来自上游 `doc/db/tables_xxl_job.sql`，不执行任何业务任务或调度变更。
- 临时 classpath 前置 root OFF 的 `logback.xml`：XXL-JOB 原生 logback 在 Spring Boot
  配置前尝试写 `/data/applogs`，在该容器/主机环境不可写。未修改上游资源。
- `xxl-sso.client.excluded.paths=/actuator/**` 让原生 SSO 拦截器跳过 Actuator；业务
  UI 的登录拦截保持原样。纯 Servlet Filter 只保护 `/actuator/**`，匿名 401、普通
  Bearer 403、管理员放行；不引入 Spring Security。
- 启动器保留原生 `XxlJobAdminApplication`，注入 2048 步启动缓冲；App context path
  改为 `/` 使固定 `/actuator` 路径可用，未调用业务 URL。

## 快速验收摘要

65 秒快速运行全部断言通过：575 次调用；356 个 Bean / 402 条依赖；35 页穷尽、无重复页；
启动 3.757 秒 / 同宿主重启 3.800 秒；路由 `/auth/login` 与 db 健康 ok/complete；
迁移/OpenAPI 端点 404 负向；启动 partial；数据库暂停后健康 DOWN、Bean 读取仍可用、
恢复后 UP；最大完整回包 15,638 字节，中位/p95 延迟 262.925 / 633.731 ms。

## 限制

- 只验证 XXL-JOB v3.4.0 / Boot 4.0.5 / Java 21 runtime / MariaDB 11.2 的一个固定提交，
  不是生产调度集群、执行器网络、任务执行、告警或长期运行验收。
- 管理 Bearer 过滤器、SSO actuator 放行和 Logback 遮蔽是测试配置，不是上游推荐。
- 启动树为 partial；迁移端点不可用；数据库暂停只验证短时恢复，不验证复制/HA/持久性。
- 未验证 UI、上游测试、执行器任务和发布包。
